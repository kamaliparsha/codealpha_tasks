# Task 3 — Sentiment Analysis

## Project Overview

This project performs sentiment analysis on movie reviews using Python and the VADER sentiment analysis tool.

## Internship

CodeAlpha Data Analytics Internship — Sentiment Analysis.

## Dataset

NLTK Movie Reviews dataset containing 2,000 movie reviews:
- 1,000 negative reviews
- 1,000 positive reviews

## Tools and Technologies

- Python
- Pandas
- NLTK
- VADER Sentiment Analyzer
- Matplotlib
- Seaborn
- Scikit-learn

## Key Results

- Total reviews analyzed: 2,000
- Positive predictions: 1,382
- Negative predictions: 617
- Neutral predictions: 1
- Evaluation coverage: 1,999 reviews
- Accuracy on non-neutral predictions: 63.53%

## Visualizations

- Predicted Sentiment Distribution
- VADER Confusion Matrix

## Output Files

The notebook generates:
- sentiment_predictions.csv
- classification_report.csv
- confusion_matrix.csv
- confusion_matrix.png
- evaluation_summary.csv
- sentiment_distribution.png

## How to Run

1. Open CodeAlpha_SentimentAnalysis.ipynb in Google Colab.
2. Run all cells in order.
3. Install the required packages if prompted.
