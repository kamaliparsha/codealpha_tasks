# CodeAlpha Data Analytics Internship — October Batch

This repository contains my completed projects for the **CodeAlpha Data Analytics Internship**, covering Exploratory Data Analysis, Data Visualization, and Sentiment Analysis using Python.

## Internship Tasks

### Task 1 — Exploratory Data Analysis (EDA)

**Folder:** `Task_1_EDA/`

- Explored the UCI Online Retail dataset.
- Performed data cleaning and preprocessing.
- Identified missing values, duplicate records, and outliers.
- Analyzed sales, products, and customer-related patterns.

**Notebook:** `01_retail_eda.ipynb`

### Task 2 — Data Visualization

**Folder:** `Task_2_Data_Visualization/`

Created visualizations to understand online retail sales:

- Monthly Retail Revenue Trend
- Top 10 Products by Revenue
- Top 10 Countries by Revenue
- Distribution of Daily Retail Revenue

**Notebook:** `CodeAlpha_DataVisualization.ipynb`

### Task 3 — Sentiment Analysis

**Folder:** `Task_3_Sentiment_Analysis/`

- Analyzed movie reviews using Python and VADER.
- Predicted positive, negative, and neutral sentiments.
- Evaluated predictions against original review labels.
- Generated a sentiment distribution chart and confusion matrix.

**Notebook:** `CodeAlpha_SentimentAnalysis.ipynb`

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- NLTK
- VADER Sentiment Analyzer
- Scikit-learn
- Google Colab / Jupyter Notebook

## Datasets

- **Online Retail:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/352/online+retail)
- **Movie Reviews:** NLTK Movie Reviews Corpus
