# Task 2 — Data Visualization

## Project Overview

This project focuses on analyzing and visualizing online retail sales data using Python. It presents sales trends, product performance, country-wise revenue, and daily revenue patterns through clear and informative visualizations.

This project was completed as part of the **CodeAlpha Data Analytics Internship — October Batch**.

## Dataset

- **Dataset:** Online Retail Dataset
- **Source:** [UCI Machine Learning Repository — Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)
- **Original Records:** 541,909
- **Features:** 8

The dataset contains online retail transaction information, including invoice numbers, product descriptions, quantities, invoice dates, unit prices, customer IDs, and countries.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Visualizations

The project includes four major visualizations:

### 1. Monthly Retail Revenue Trend
Analyzes revenue across different months to identify sales patterns and monthly performance.

### 2. Top 10 Products by Revenue
Identifies the ten products generating the highest revenue.

### 3. Top 10 Countries by Revenue
Compares revenue generated by different countries and highlights the strongest markets.

### 4. Distribution of Daily Retail Revenue
Visualizes daily revenue patterns to understand variations in retail sales.

## Key Objectives

- Understand retail sales patterns through visual analysis.
- Identify top-performing products.
- Compare revenue across countries.
- Analyze monthly and daily sales trends.
- Present business insights using Python visualizations.

## Project Notebook

`CodeAlpha_DataVisualization.ipynb`

The notebook contains the Python code, data processing steps, visualizations, and observations.

## How to Run the Project

1. Open `CodeAlpha_DataVisualization.ipynb` in Google Colab or Jupyter Notebook.
2. Download the Online Retail dataset from the UCI Machine Learning Repository.
3. Upload the dataset when prompted by the notebook.
4. Execute the notebook cells sequentially.
5. Review the generated charts and observations.
